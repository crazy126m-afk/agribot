1. **Brand Name**: **AgriBot Pro** (`DVG · AGRIBOT AI`)
2. **Gen-Z Cyber Palette**: Obsidian `#060a08` base, frosted glass bento cards, neon accents (`#00f59b`, `#fbbf24`, `#38bdf8`, `#fb7185`).
3. **Davangere (DVG Special)**:

   - **ಮೆಕ್ಕೆಜೋಳ (Maize - Davangere Gold)** & **ಅಡಿಕೆ (Arecanut - Channagiri Rashi)** special guides.

## 📱 How to Run
- **Live Local Web App**: `http://localhost:8080`
- **Install on Android Phone**: Open in Chrome on Android -> Tap `⋮` -> "Install app" / "Add to Home Screen".
- **Compile APK**: Pre-configured with Capacitor and GitHub Actions (`.github/workflows/build-apk.yml`).
